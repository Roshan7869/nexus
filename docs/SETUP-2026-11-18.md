## 0. The one-paragraph version

NEXUS never ran on this machine for a mundane reason: **there is no Python**, so not one
module imports. Behind that sit four genuine code defects and an empty data layer. Fix the
toolchain, fix four bugs, then populate clusters → edges → embeddings → outcomes in that
order. Everything else (Rust, WSL, Ollama, TEI) is optional and currently a distraction.

## C. Data — the real reason routing is dumb

Flags are already correct in `.env`; **they are inert until this data exists.**

| # | Empty input | Consequence today | Populate with | Order |
|---|---|---|---|---|
| C1 | `resources` — 27 rows | Routing picks from 27 of a potential 3k | `uv run python scripts/absorb_repo.py <repo>` | 1st |
| C2 | `cluster_definitions` — **0 rows** | `NEXUS_CLUSTER_ROUTING` cannot fire; v5's L1 short-circuit needs a cluster pool ≥50 | Seed clusters, assign `resources.cluster` + `cluster_membership` | 2nd |
| C3 | `resource_edges` — **0 rows** | `NEXUS_GRAPH_LANE=1` folds nothing | `scripts/densify_kg.py` | 3rd |
| C4 | embeddings — **0 vectors** | Semantic lane sees nothing; "pedantic quality auditor" cannot match `egm-structural` | `uv pip install fastembed onnxruntime` then backfill | 4th |
| C5 | `outcome_log` — **0 rows** | Thompson has no beliefs; `min_samples` gate never opens | Real `task_complete` reports from live sessions | 5th |

**Embedding choice:** start with **`all-MiniLM-L6-v2` (384-dim)**. The existing FAISS index and
`bit[384]` sqlite-vec lane were built with it → **zero re-embedding**. `bge-small-en-v1.5` scores
better on MTEB but invalidates every stored vector and needs query-prefix discipline — a later
migration, not a starting point.

**FAISS is stale:** `db/faiss/resources.index.meta.json` reports `n_total: 1200`, built
`2026-07-11` at commit `40a708b` — ~36% of the active corpus unindexed. Rebuild via
`scripts/rebuild_faiss.py` after C4.
